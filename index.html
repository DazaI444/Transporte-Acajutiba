Sistema de Transporte TFD Acajutiba – Aplicativo e Painel Administrativo

Documento Técnico + Protótipos

Data: 27/08/2025

1. Objetivo do Projeto

Este sistema visa facilitar a gestão do transporte de pacientes TFD, permitindo agendamento remoto, acompanhamento das viagens e controle de frota e motoristas. Ele atende à Secretaria de Saúde de Acajutiba, motoristas e pacientes TFD, garantindo eficiência e transparência.

2. Escopo do Sistema

  • Aplicativo Paciente TFD: agendamento, acompanhamento de viagem e notificações.
  • Painel Web Administrativo: gestão de solicitações, frota, motoristas e relatórios.
  • Relatórios: métricas de transporte, consumo de combustível e custos.
  • Integração em tempo real entre App e Painel.

3. Fluxo do Sistema

Fluxo: Solicitação → Aprovação → Agendamento → Execução → Conclusão → Relatórios

5. Arquitetura Tecnológica

  • Frontend App: Flutter / React Native
  • Frontend Painel: React + Tailwind CSS
  • Backend: Node.js / Python (API RESTful)
  • Banco de Dados: MySQL / PostgreSQL
  • Hospedagem: Cloud

6. Requisitos Técnicos

  • Acesso à internet para sincronização em tempo real
  • Responsividade para desktop, tablet e mobile
  • Segurança: autenticação e criptografia de dados
  • Compatibilidade do App: Android e iOS
